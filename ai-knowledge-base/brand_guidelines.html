Brand guidelines

The design system for the NavVis mobile challenge app: colours, type, spacing and how each part of the screen looks.

The values come from the public NavVis website (navvis.com, read on 2026-11-20): its stylesheet, CSS variables and fonts. Some had to be adjusted for contrast or for dark mode, and the site has no mobile app styles. Every value marked "chosen" below is my own choice, made to fit the site.

What the website uses

  • Primary blue #1979E4 for buttons and links (the most used colour in the stylesheet).
  • Accent green #1FE179 for secondary buttons and link hover.
  • Page background #F4F6FA, text #000000, light grey #EBEBEB, dark grey #353436.
  • Error red #DF0035 (and a brighter #F80945).
  • Poppins for headings, menus and buttons (weight 700), Open Sans for body text (weight 400).
  • Square corners: every border radius on the site is 0.

The NavVis logo is not used anywhere in the app.

Colour tokens

The site has no dark theme of its own, only black sections. All dark values are chosen. Android 12 dynamic colour (colours from the wallpaper) is turned off, so the brand colours are always used.

Typography

Both fonts are on Google Fonts under the SIL Open Font License, so they can be bundled with the app. Only two Poppins weights are bundled, to keep the APK small.

The website uses weight 700 for menu titles and buttons. In the app, 700 only goes on the app name; at 14 sp on a phone, 500 reads better. Chosen.

Spacing and shape

  • 16 dp side padding everywhere.
  • Rows and section headers: 12 dp top and bottom padding, 1 dp divider under each.
  • Banner: 8 dp top and bottom, 16 dp left, 8 dp right (the Retry button brings its own padding).
  • Footer: 24 dp top and bottom.
  • Corners are square (0 dp) on buttons, menus and banners, like the website. Spinners stay round.
